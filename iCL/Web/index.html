Direction

Stop the motor to change direction.

Space bar also triggers Emergency Stop while connected. E-Stop bypasses the decel ramp entirely (immediate stop), unlike the Stop button.

Note: the connection-loss warning above is informational only. The Teensy's step generator is a free-running hardware timer that doesn't depend on the USB link being alive — only the drive's power or a physical E-Stop can guarantee the motor stops if the serial connection is down.

Settings

Steps per revolution must match the drive's SW1–SW4 microstep DIP switches (default 400 = all on). Invert flips DIR polarity in software if CW/CCW came out backwards for your wiring. Both require the motor to be stopped, matching the firmware's own rule. This drive's firmware has no persistent storage — these reset to the sketch's compiled-in defaults every time the Teensy powers up, so this app re-syncs them from the device on each Connect.

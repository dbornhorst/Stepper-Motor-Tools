This tool needs the Web Serial API to talk to your USB-to-RS485 adapter. That's only available in Google Chrome or Microsoft Edge on a desktop or laptop computer.

It will not work in Safari, Firefox, or on most mobile browsers.

Settings

Baud rate / data format / slave ID here must match the drive's DIP switches (or its current register values). They only take effect on your next Connect — they don't change anything on the drive itself. To change the drive's own configuration, use the Danger Zone below.

Danger zone — write configuration to the drive

These write to the drive's own memory and save to EEPROM (limited write cycles — don't use these routinely). Only meaningful when connected. After using one of these, update the Settings above to match, then disconnect and reconnect.

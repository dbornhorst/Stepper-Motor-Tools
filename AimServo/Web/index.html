Browser not supported

This tool needs the Web Serial API to talk to your USB-to-RS485 adapter. That's only available in Google Chrome or Microsoft Edge on a desktop or laptop computer.

It will not work in Safari, Firefox, or on most mobile browsers.

Settings

This drive is fixed at 19200 baud / 8N1 (no configurable baud/parity register), so the app always opens the serial port with those settings — only the Slave ID here needs to match the drive. Settings are stored per browser origin: values saved while testing locally won't carry over to the GitHub Pages URL, or vice versa.

Danger zone — write configuration to the drive

These write to the drive's own memory and save to EEPROM (limited write cycles — don't use these routinely). Only meaningful when connected.
